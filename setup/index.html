Supported profiles and model limits

STM32F407VGT6 only. The HSI16 robot uses TIM2 PWM, GPIO direction and TIM3/TIM4 quadrature. The PLL168 profile is for passive signal discovery of the qualified TIM2 capture and TIM3 PWM routes.

The robot uses observed pin signals and model state. Firmware odometry and setpoints require the optional example-v1 observer and its documented memory layout.

One execution slot per server. Robot runs support up to 30 virtual seconds. Other peripherals and routes may be incomplete. TIM9 operation, ITM/SWO output and SRAM bit-band remain unqualified.

Ideal rolling with no slip or collisions. Averaged drivers. Illustrative physical parameters. No validation against physical hardware.
